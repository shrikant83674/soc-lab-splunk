# SOC Lab - Splunk & SOAR

## Project Overview

This repository contains a hands-on SOC Level 1 and Level 2 security operations lab built using Splunk Enterprise and Splunk SOAR.

## Lab Components

* Splunk Enterprise (Ubuntu VM)
* Splunk SOAR 7.0 (Oracle Linux VM)
* 17 GB BOTS security dataset
* Custom dashboards
* Detection rules
* Incident investigation reports
* SOAR automation workflows

## Skills Demonstrated

* Log analysis
* Threat hunting
* SPL query development
* Alert triage
* Incident investigation
* Detection engineering
* Security automation
* MITRE ATT&CK mapping
